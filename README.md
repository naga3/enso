# イチエンソーマン

筆で一円相を描くゲーム。紙に薄く透けたお題の一円相を、一筆でなぞる。縦長の画面で、スマホでもそのまま遊べる。

https://naga3.github.io/enso/ で遊べる（main に push すると GitHub Pages に出る）。

手元では `npm start`（`python3 -m http.server 8031`）で http://127.0.0.1:8031/ を開く。ES modules なので file:// では動かない。`#5` のように番号を付けるとそのお題から始まる。

## 太さの決め方

- **速さ**: ゆっくり動かすと太く、速いと細い。筆先はばねで手に少し遅れてついてくるので、太さは急に変わらない
- **溜まり**: 止まっていると墨が溜まり、太く広がる（入りの溜め）
- 筆は 44 本の毛の集まり。毛ごとに墨の量を持ち、乾いた毛から紙のきめに沿ってかすれる。速いほどかすれやすい
- 筆を動かしたまま離すと払い、止まって離すと止め
- 筆圧は使わない

お題も同じ筆（`src/brush.js`）に架空の手の動き（`src/odai.js`）を通して描く。だからお題の太さは、どれも手で出せる。筆の数値を変えるとお題の見た目も変わる。

## 採点（`src/score.js`）

点数は見たままの重なり。お題と自分の線を升目（256×256）に塗り、次の二つを合わせる（F 値）。少しのずれ（紙の幅の 0.3%）は許す。

- 足りない: お題のうち、墨が乗っていない割合。結果の紙では朱
- はみ出し: 自分の墨のうち、お題の外にある割合。結果の紙では青

細すぎると足りず、太すぎるとはみ出すので、太さは時間を測らなくても点に出る。ほかに、入り・中ほど・抜けのどこが太い（→もっと速く）・細い（→ゆっくり）か、回る向きが逆かを助言に出す。お題ごとの最高点は localStorage に残す。

## 試験

`npm test`（node --test）。お題どおりなら満点近く、速いと足りず、遅いとはみ出し、ずれると両方増え、逆回りは助言に出ることを見る。
